# AI Context Hub 3.7.0 (VS Code)

## Wat is nieuw
- **Pipelines voor de balk**: de commando's waarmee PyCharm Git de pipelines van je branches in de titelbalk toont (`aihub.bar.pipelineRuns`, `pipelineRun`, `pipelineLog`, `pipelineStatus`, `pipelineRerunPlan`, `pipelineRerun`, `pipelineRerunFailed`, `pipelineCancel`, `pipelineFix`, `pipelineRetryNow`). Elk commando antwoordt met de JSON van de CLI of met een fout van een vaste soort (afgemeld, geen CLI, CLI te oud, geen repo, mislukt); de extensie toont zelf geen pop-ups. `pipelineRuns` leest alle repo's van de set in één proces. Een blijvende fout wordt per map 5 minuten onthouden. Opnieuw draaien schrijft alleen de wijzigingen naar een privé tijdelijk bestand, dat direct daarna weer wordt verwijderd. `pipelineFix` zet de tekst voor het herstel in de chat, en de gebruiker drukt zelf op Enter. PyCharm Git toont de knoppen pas in een volgende release.
- **Smart Checkout in plaats van een CLI-vlag.** Wissel je met niet-gecommit werk, dan krijg je de keuze zoals in PyCharm. Een melding met de technische tekst `--mode worktree` komt niet meer. Elke fout staat in één gewone zin, met Show Details voor wie meer wil zien.
- **Een kloon die niet te vinden is, kun je kiezen.** De kloon wordt gezocht via de remote of een losse mapnaam. Vindt de extensie er geen, dan biedt ze "Choose Folder…" aan. De gekozen map wordt gecontroleerd: een kloon van een andere repo wordt geweigerd. Daarna wordt de map onthouden en de actie herhaald. Dat werkt ook als het probleem pas in een open resultaat wordt gemeld (Add Repository to Set).
- **Een kloon via de zoekfunctie**: je ziet waar hij komt (het pad wordt in het midden ingekort), je ziet de voortgang en je kunt annuleren (dan stopt het hele git-proces). Undo verwijdert de kloon, ook als hij alleen-lezen git-bestanden heeft. Een onderdeel dat niet weg kan, wordt bij naam genoemd.
- **Geen git-variabelen van een andere repo**: ook de processen van de extensie erven geen `GIT_DIR`, `GIT_WORK_TREE`, `GIT_INDEX_FILE` en verwante variabelen meer, zoals in aihub 1.8.0.
- **De knoppen vragen aihub 1.8.0.** Met een oudere CLI krijg je een gewone zin met Copy update command / Update now.

## Snelheid
Er is geen timer, watcher of werk in `activate()` bijgekomen; alleen de commando's zijn geregistreerd. Er draait één `aihub`-proces per aanroep, alleen als de balk erom vraagt. Het ritme van 15 s terwijl een eigen run loopt, zit aan de kant van de balk. Een rode run kost in de CLI één keer een lezing van de timeline en de testruns, en het antwoord wordt bewaard.

## Compatibiliteit
- Vraagt aihub 1.8.0 voor de knoppen in de titelbalk. De statusbalk en de panelen werken ook met een oudere CLI, zoals in 3.6.0.
- PyCharm Git 0.28.0 werkt met deze versie; de pipeline-knoppen komen met een volgende PyCharm Git.
- `BarState`: er zijn alleen velden bij gekomen.

## Validatie
- Op de releasebron: typecheck en `npm run test:unit` groen; de telling staat in de release-PR. CI (`test`, `vscode`) was groen op elke PR.
- **Live bewezen:**
  - `scripts/live/bar.js` in PyCharm Git (een eigen VS Code-kopie, synthetische repo's) met deze hub van staging 0f9a828: 104 PASS en 1 FAIL. De FAIL is een verouderde controle in PyCharm Git. Onderdelen: Open Story, het menu met de storybranches, een echte wissel (bevestigd met git), de uitlijning van het overzicht, en Open in Own Window met een ongewijzigd setbestand.
  - Choose Folder… in een geïsoleerd profiel (#294) en Undo van een alleen-lezen kloon (#288).
  - De pipeline-commando's: de argumentbouwers met de echte CLI tegen `ferron-test` (#291), niet via de knoppen.
- **Alleen met unit-tests bewezen:** de foutzinnen met Show Details, het 5-minutengeheugen voor blijvende pipelinefouten, en het opruimen van het tijdelijke bestand.
- De vsix van deze release komt van precies de getagde bron. De sha256 staat naast de vsix in de GitHub-release `vscode-v3.7.0`.

## Known issues
- De pipeline-knoppen zijn pas zichtbaar met een volgende release van PyCharm Git.
- De melding "achter op de doelbranch" en het overzicht met echte waarden zijn nog steeds alleen in tests bewezen, niet in een venster met focus.

## Installatie
`Install-Extensions`, of `code --install-extension ai-context-hub-3.7.0.vsix` (controleer de sha256). Installeer aihub 1.8.0 erbij: `npm i -g @ferronhooi/aihub`.
