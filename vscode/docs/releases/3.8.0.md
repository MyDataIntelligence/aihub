# AI Context Hub 3.8.0 (VS Code)

## Wat is nieuw
- **Repo's als set, op drie manieren, met één motor** (`aihub.bar.openReposAsSet`):
  - **New Set…** (`aihub.bar.newSet`) vraagt welke repo's (ook "Clone from Azure DevOps…"), daarna een nieuwe branch voor allemaal of per repo een bestaande, en "Link to a story?".
  - **Open as Set…** vanuit het linkermenu en de repo-browser.
  - Een repo die nog niet op de pc staat, wordt eerst gekloond. Heeft de story al een set, dan opent die set. Anders opent de nieuwe set in een nieuw venster, met Undo. `noSet` opent één repo in een eigen venster.
- **Add Repository… in een venster met één repo**: het venster wordt een set. De huidige repo blijft op zijn branch en in zijn map; de nieuwe repo's krijgen een worktree.
- **Een set waarvan de eerste map buiten de setmap ligt**, wordt herkend via het workspace-bestand.
- **De commando's voor de wiki- en story-browser** (`aihub.bar.wiki*`, `aihub.bar.story*`); PyCharm Git 0.30.0 toont de wiki-browser; de knoppen van de story-browser volgen later. De commando's van de repo- en pipeline-browser zaten al in 3.7.x; nu toont PyCharm Git 0.30.0 ze.
- **Een pipeline-run** opent ook in een venster zonder die repository (per project).
- **Zoeken naar Azure DevOps** werkt ook als elke kloon in een worktree-set staat.
- **Setbestanden in een oudere vorm** geven geen "#[object Object]" meer.
- **Achterlopen op de doelbranch bij het openen**: had het venster op dat moment geen focus, dan ging die controle verloren. Nu wordt ze één keer ingehaald zodra het venster focus krijgt, zonder timer of extra proces (#330).
- **Update from Target** geeft altijd `--target` mee en meldt geen "updated" als er niets veranderde (#332).
- De knoppen vragen **aihub 1.9.0**.

## Snelheid
Er is geen timer of watcher bijgekomen, en in rust gebeurt er niets. Elke actie is één `aihub`-aanroep, alleen op een klik. De lijsten van de browsers worden gedeeld en een paar minuten onthouden.

## Compatibiliteit
- Vraagt aihub 1.9.0 voor de knoppen.
- PyCharm Git 0.30.0 heeft de repo-browser, de pipeline-browser, New Set… en Add Repository…. De wiki- en story-browser komen in een volgende PyCharm Git.
