# AI Context Hub 3.4.0 (VS Code)

## Wat is nieuw
- **Geen git-processtorm meer in Worktree Sets.** De echte performance-log van de werklaptop liet zien:
  - 1519 git-starts in één minuut;
  - reads tot 2 minuten;
  - per repo 4 à 5 git-calls, voor alle sets tegelijk, zonder limiet.

  Nu:
  - per repo één `git status --porcelain=v2 --branch`; de remote branch wordt uit `.git` gelezen;
  - hoogstens 2 git-processen tegelijk voor de hele extensie;
  - een status blijft bewaard tot git iets in die repo wijzigt of er een bestand in wordt opgeslagen;
  - alleen de set van dit venster staat uitgeklapt, en een verborgen view leest niets;
  - de branch staat direct in de statusbalk (uit `.git/HEAD`) terwijl de volledige status laadt.
- **Run Robot Test...** in het palet, het Robot tests-menu, de play-knop op een `.robot`-bestand, de Explorer en de paneeltitel. Daarnaast **Run this test** boven elke testcase.
  - Je kiest suite, test en omgeving (alleen uit team.yaml).
  - De run draait in een terminal met de runner en de venv van de repo.
  - Daarna PASS/FAIL met Open log.html en Open report.html.
- **Clean Up Worktrees...**: elke worktree met grootte, laatste activiteit, lokaal werk, gemerged, PR en story.
  - Afgeronde worktrees zonder lokaal werk staan aangevinkt.
  - Verwijderen gaat veilig en zegt hoeveel ruimte er vrij is gekomen.
  - Herinnering: hoogstens één keer per dag, normaal wekelijks, eerder bij 3 of meer.
- **Repo-opener:** stap 1 van New Worktree Set… en van "Repositories on a branch…" is één zoekbare meerkeuzelijst.
  - Bovenaan je groepen (★) en recente repo's, daarna per Azure DevOps-project de repo's ("not cloned ↓" als ze nog niet lokaal staan), daarna de lokale clones.
  - Een repo die nog niet lokaal staat, wordt eerst gekloond.
  - Je kunt de keuze opslaan als groep (persoonlijk of in team.yaml).
  - Stap 2 heeft ook "Open as they are".
  - Instelling `aihub.reposRoot`.

## Snelheidsgate
Gemeten op 2026-11-24 op Windows 11 met VS Code 1.147.0:
- geïsoleerd profiel, geminimaliseerd, onder de desktop-lock, alleen via CDP;
- synthetische repo's zonder login.

Nulmeting: 3.3.0 + aihub 1.2.0. Nieuw: 3.4.0 + aihub 1.3.0.

**Worktree Sets op een "trage laptop":** een git-wrapper wacht 200 ms per start. 3 sets van 4 repo's, venster op set 0, de view open, één Refresh, 2 minuten.

| Meting | 3.3.0 | 3.4.0 |
|---|---:|---:|
| git-processen in 2 minuten | 125 | **18** |
| git-processen in de eerste minuut | 121 | **16** |
| Meest tegelijk | 42 | 5 (de extensie houdt zich aan 2; de rest zijn git-calls van de aihub-CLI) |
| Tot de status van de open set zichtbaar is | 5,8 s | **2,0 s** |

**Opstart (mediaan, 3 verse profielen, 2 starts per profiel):**

| Meting | 3.3.0 | 3.4.0 |
|---|---:|---:|
| `activate()` | 11,9 ms | 11,8 ms |
| Eerste volledige status in de statusbalk | 5,3 s | 5,3 s (de branch staat er sinds 3.4.0 direct) |
| Processen van de extensie in de eerste 30 s | 1 | 1 |

CPU van de Node-services tijdens 30 s typen in `main.py` (herhaalmeting, 2 profielen per variant): 3.3.0 1,28 / 0,88 s, 3.4.0 0,88 / 0,73 s. Niet trager; de meting is ruisgevoelig (de eerste nulmeting gaf 0,03–0,88 s).

**Nog niet gemeten:**
- op de VM van de werklaptop;
- met een echte login.

Draai daar na een werkdag "AI Context Hub: Show Performance Report" en exporteer.
