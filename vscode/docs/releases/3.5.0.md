# AI Context Hub 3.5.0 (VS Code)

## Wat is nieuw
- **Een worktree die al bestaat: dezelfde vraag als de CLI.** Open Repo Set, New Worktree Set en "Open story" in My Stories gebruiken een branch die al een worktree buiten de set heeft. Dan toont de extensie een dialoog met drie keuzes:
  - Move it into this set (aanbevolen; werk en branch gaan mee);
  - Reuse it where it is;
  - Recreate it.

  Daarna draait hetzelfde commando opnieuw met de gekozen `--existing`. Annuleren verandert niets. De keuzes komen uit `needsChoice` van aihub 1.6.0.
- **Geen venster bij een wissel binnen de set.** Wisselt de CLI repo's binnen de set die dit venster al toont (aihub 1.6.0, `stays`), dan opent de extensie geen venster en toont ze alleen de regel.
- **De eigen branch per repo in de tooltip** van de set in de statusbalk, als die afwijkt van de branch van de set (`repos[].branch` of `set.branches` van `aihub status`).

## Snelheid
Geen nieuwe timer, watcher of achtergrondwerk. De dialoog komt alleen na een commando dat de gebruiker zelf start; per gekozen antwoord is er één extra `aihub`-aanroep.

## Compatibiliteit
Voor de dialoog en de wissel zonder venster is aihub 1.6.0 nodig. Met een oudere CLI verandert er niets aan het gedrag van 3.4.0.
