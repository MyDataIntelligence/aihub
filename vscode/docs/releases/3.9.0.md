# AI Context Hub 3.9.0 (VS Code)

## Wat is nieuw
- **Teaminstellingen** (`aihub.bar.teamShow|teamSchema|teamValidate|teamPreview|teamEdit|teamInit`, #314): de commando's achter de Team Settings-pagina's van PyCharm Git. Ze starten één proces per aanroep, alleen als de pagina erom vraagt; teksten gaan via privé tijdelijke bestanden.
- **Run End to End, de bridge** (#341, #346): `aihub.bar.storyAction` opent of hergebruikt de set van een story, start de story als die nog geen branches heeft, en start de opencode-tab met `/<actie> <id>`. Een ander venster krijgt een eenmalige actie die hoogstens 2 minuten oud mag zijn. Verder `storyPrompt`, `storyPromptSave`, `storyPromptReset`, `storyPrompts`, `storyRunState`, `criteriaStatus`, `criteriaProposal` en `criteriaApply`. De opties van het dialoog (Plan first, Fabric, Set Active, concept-PR) gaan mee in de prompt. Stop zet de run stil en stuurt Escape naar de opencode-tab (het start er nooit een).
- **Change with Agent** (`aihub.bar.change*`, #349): een wijziging zonder kloon (remote) of in een werkkopie op een nieuwe branch, met de agent in een terminal van dit venster, in een nieuw venster of in Windows Terminal. Verder de stand (diff en of de agent nog werkt), push, weggooien, stoppen, en een wijziging naar een werkkopie halen.
- **Zoeken en vragen over meer repositories** (#350, #351, #352): `browseSearch` met een scope, `aihub.bar.ask*` (Ask Agent about Selected, open de gevonden repositories als set) en `aihub.bar.changeSuggestFiles` (+ related files).
- De knoppen vragen **aihub 1.10.0**.

## Snelheid
Er is geen timer of watcher bijgekomen. Eenmalige controles na de activatie lezen elk één klein bestand (de wachtende actie van een setvenster na 3 s, de wachtende agent van een nieuw venster na 2 s), zonder proces. Elke actie is één `aihub`-aanroep, alleen op een klik.

## Compatibiliteit
- Vraagt aihub 1.10.0 voor de knoppen.
- De pagina's voor Team Settings en Run End to End komen in PyCharm Git 0.31.0. Tot dan zijn de commando's er wel, maar zonder knoppen.

## Validatie
- Op de releasebron: typecheck en `npm run test:unit` groen; de telling staat in de release-PR. CI (`test`, `vscode`) was groen op elke PR.
- **Live bewezen**:
  - **Team Settings**: engine en UI live 41/41, en opnieuw bewezen in een geïsoleerde run: de volledige run met 42 checks, daarna het Entry-bord 5/5 met een isolatiecheck, ook met APPDATA en LOCALAPPDATA afgeschermd (extensions #1117, #1118).
  - **Run End to End (de motor)**: via de CLI en de prompts tegen `ferron-test` (zie de notes van aihub 1.10.0).
  - **Zoeken met een scope en + related files**: de motor live tegen `ferron-test`; de bridge-commando's met typecheck en unit-tests.
- **Nog niet bewezen:**
  - Het dialoog en de bridge in een live VS Code-venster, ook voor Change with Agent en Ask Agent.
  - Een volledige `/story-run` door een echte agent.
  - Stop die Escape naar een echte opencode-tab stuurt.
- De vsix komt van precies de getagde bron; de sha256 staat naast de vsix in de GitHub-release `vscode-v3.9.0`.

## Installatie
`Install-Extensions`, of `code --install-extension ai-context-hub-3.9.0.vsix` (controleer de sha256). Installeer aihub 1.10.0 erbij.
