# AI Context Hub 3.9.1 (VS Code)

## Wat is nieuw
- Geen wijziging in de extensie zelf. Deze versie hoort bij aihub 1.10.1, waarin `aihub pr create` het titelpatroon van het team gebruikt (#356). De preview van Team Settings toont die titel.

## Context
Patchrelease, samen met aihub 1.10.1.

## Snelheid
Niets veranderd: geen timer, geen watcher, niets in rust.

## Compatibiliteit
- Vraagt aihub 1.10.0 of nieuwer voor de knoppen; 1.10.1 voor de titel uit team.yaml.
- Werkt met PyCharm Git 0.31.x.

## Validatie
- `npm run typecheck` en `npm run test:unit` op de releasebron; de telling staat in de release-PR.
- Geen nieuwe live-check: de extensiecode is gelijk aan 3.9.0.

## Known issues
- Geen nieuwe.

## Installatie
`install\Install.cmd` keuze [1] installeert aihub en de extensie, of installeer de vsix uit deze release. Herstart daarna VS Code helemaal.
