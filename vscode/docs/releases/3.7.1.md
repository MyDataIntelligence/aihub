# AI Context Hub 3.7.1 (VS Code)

## Wat is nieuw
- **Achter op staging werkt vanzelf bij.** `aiContextHub.behindTarget` staat nu standaard op `auto`. Een repo van de set die achterloopt, zonder conflicten, zonder overlap met niet-gecommit werk en zonder lopende merge of rebase, wordt vanzelf bijgewerkt en nooit gepusht. Daarna komt een melding met Undo. Bij een conflict krijg je de vraag. Elke repo van de set wordt bekeken.
- **Create Pull Requests zegt wat het doet.** De voortgang staat per repo ("test-consumer (1 of 2): push and pull request"). Als het klaar is, komt er een melding met **Open Pull Request(s)**, ook als een deel misging, en daarna worden de PR's opnieuw gelezen, zodat "none yet" en "2 missing" verdwijnen. Bevestig je zonder vinkje, dan zegt de extensie dat. Een aanroep die over zijn tijd gaat, stopt nu met al zijn processen.
- **Een PR van de set wordt altijd gevonden.** De PR's worden per branch van de set gelezen, van iedereen en in elke staat. Eerder waren het de nieuwste 100 van jezelf, zodat een oudere PR of een PR van een collega als "none yet" verscheen.
- **Update All biedt "Update from Target"** voor een branch met eigen commits. Die branch kon niet vooruitgespoeld worden, en je hoefde dit niet meer zelf te doen.
- **Duidelijkere meldingen.** Een repo die niet op Azure DevOps staat, geeft "this repository is not on Azure DevOps", niet "you are not signed in". De statusbalk toont "#3748" of de titel uit het setbestand, nooit "#3748 (unknown)".
- **Open Story op nummer** geeft de branch `feature/<id>-<titel>` (of `feature/<id>-story`), nooit `feature/<id>-`. De titel wordt opgehaald vóór de naam gemaakt wordt.
- **Kloon kiezen:** de motor geeft per repo alle klonen (`repositories[].clones`, met de kloon in gebruik) en `aihub.bar.useClone`. PyCharm Git 0.29.1 toont "· 2 clones" en "Choose Clone…".
- **Pipelinebrowser (motor):** `aihub.bar.browsePipelines`, `browsePipeline`, `browseRunPlan`, `browseRun`, `browseArtifacts`, `browseArtifactFiles`, `browseArtifactOpen`, `browseDraftCreate`, `browseDrafts` en `browseDraftDelete`. De balk toont dit nog niet. De repository-browser (`aihub.bar.browse*` voor repo's, branches en bestanden) zat ook al in 3.7.0 maar stond niet in die notes.

## Snelheid
Er is geen timer of watcher bijgekomen, en in rust gebeurt er niets.
- Het lezen van de PR's kost één `aihub pr list` per branch van de set. Meestal is dat één aanroep, net als eerder, met een maximum van drie.
- Na Create Pull Requests worden de PR's één keer opnieuw gelezen.
- Het automatisch bijwerken draait alleen voor een repo die achterloopt en veilig is, na de fetch die er al was.

## Compatibiliteit
- De knoppen vragen **aihub 1.8.2**. Met een oudere CLI krijg je een gewone zin met Copy update command / Update now.
- PyCharm Git 0.29.1 (Choose Clone…, de leesbare reponaam in de Commit-weergave, het automatisch bijwerken buiten een set). PyCharm Git 0.29.0 werkt ook, maar zonder Choose Clone.
- Wil je de oude vraag terug, zet dan `aiContextHub.behindTarget` op `ask`.

## Validatie
- Op de releasebron: typecheck en `npm run test:unit` groen; de telling staat in de release-PR. CI (`test`, `vscode`) was groen op elke PR.
- **Live bewezen:** dat de CLI-aanroep van Create Pull Requests werkt (PR's !1261 en !1262 in `ferron-test`, daarna op abandoned gezet). De pipelinebrowser met synthetische pipelines (#310).
- **Alleen met unit-tests bewezen:**
  - de voortgang en de links van Create Pull Requests;
  - het stoppen van de procesboom bij een time-out;
  - de PR-aanroepen per branch;
  - Update from Target;
  - de N7-tekst;
  - de statusbalk zonder "(unknown)";
  - de standaard `auto`;
  - de naam bij Open Story op nummer.
- **Niet live bewezen in een venster:** deze versie als geheel. De persona-ronde 2 liep op 3.7.0 met staging-builds van daarvoor.
- De vsix van deze release komt van precies de getagde bron. De sha256 staat naast de vsix in de GitHub-release `vscode-v3.7.1`.

## Known issues
- De stille afloop van Create Pull Requests in de persona-ronde (geen enkele logregel na de keuzelijst) is niet tot op de oorzaak teruggevonden. Bevestigen zonder vinkje meldt zich nu wel, en elke andere weg geeft voortgang en een slotmelding.
- De pipelinebrowser en de pipeline-knoppen zijn pas zichtbaar in een volgende release van PyCharm Git.

## Installatie
`Install-Extensions`, of `code --install-extension ai-context-hub-3.7.1.vsix` (controleer de sha256). Installeer aihub 1.8.2 erbij: `npm i -g @ferronhooi/aihub`.
