# AI Context Hub 3.2.0 (VS Code)

Deze release bevat ook alles van 3.1.2, waarvoor geen aparte tag is gemaakt.

## Wat is nieuw
- **My Stories** (Explorer, standaard ingeklapt): story → repository → branches.
  - Een ★ markeert de branch waar je op werkt; oude branches zijn gedimd.
  - Per branch zie je het label, lokaal werk, gepusht en de PR.
  - Acties: Open Story…, Link Branches…, Mark as Current ★ / Old / Parked, Change Label…, Unlink, Remove Branch and Worktree… (gooit nooit lokaal werk weg) en Open Worktree in New Window.
  - De weergave leest alleen als hij zichtbaar is.
- **De ★ volgt waar je werkt.**
  - Hij telt opslaan, bewerken, focusminuten en commits/checkouts uit de reflog.
  - Smalle watchers en geen pollende timer; hij schrijft hooguit één keer per minuut.
  - Instelling `aihub.storyWorktrees.autoMarkCurrent`: ask (standaard), auto (met Undo) of off.
- **Open Repo Set** (voorheen "Repos op branch openen") wisselt echt van venster:
  - de extensie opent de set zelf in dit venster of in een nieuw venster;
  - in stap 2 is de huidige branch voorgeselecteerd, dus één Enter is genoeg;
  - elke stap toont "stap n/3";
  - de statusbalk toont de set ook na het wisselen van checkouts.
- **Minder processen.**
  - Uit 3.1.2: Worktree Sets leest een set één keer per verversing in plaats van één keer per rij.
  - Uit 3.1.2: automatische refreshes wachten langer na een trage read.
  - `aihub --version` draait nog hooguit één keer per dag.
  - Met aihub 1.1.0 kost een statusread 3 git-processen in plaats van 6.

## Snelheidsgate (opstart en typen)
Gemeten op 2026-11-24 op Windows 11 met VS Code 1.147.0 in een geïsoleerd profiel:
- geminimaliseerd en zonder focus;
- een synthetische kloon van test-project zonder login;
- per variant 3 verse profielen, telkens een niet-gemeten eerste start en daarna twee gemeten starts.

Nulmeting: 3.1.1 + aihub 1.0.9. Nieuw: 3.2.0 + aihub 1.1.0.

| Meting (mediaan) | 3.1.1 | 3.2.0 |
|---|---:|---:|
| `activate()` | 10,2 ms | 10,0 ms |
| Eerste status in de statusbalk | 4,2 s | **3,4 s** |
| Processen van de extensie in de eerste 30 s | 2 (`--version`, `bar`) | **1** (`bar`; de versie komt uit de cache) |
| node / cmd onder VS Code in de eerste 30 s (eerste start) | 2 / 2 | 1 / 1 |
| CPU van de Node-services in 30 s rust | 0,16 s | 0,23 s |
| CPU van de Node-services tijdens 30 s typen in `main.py` | 0,62 s | 0,80 s |
| Processen van de extensie tijdens het typen | 0 à 1 | 0 à 1 |

De opstart is niet trager dan 3.1.1, maar juist sneller. De tracker van de ★ kost tijdens het typen ongeveer 0,15 s CPU per 30 s extra: ongeveer 0,5 % van één kern. Hij start daarbij geen processen.

**Nog niet gemeten:**
- op de VM van de werklaptop;
- met een echte login.

## Compatibiliteit
Werkt met aihub 1.0.2 of nieuwer. Voor My Stories, Open Repo Set en de snellere statusread is aihub 1.1.0 nodig.
