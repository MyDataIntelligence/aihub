# AI Context Hub 3.0.0 (VS Code)

## Wat is nieuw
- Volledig nieuwe, dunne extensie over de aihub CLI (`@ferronhooi/aihub`); vervangt de bevroren 2.x-extensie met Java-core. Zelfde extensie-id `FerronHooi.ai-context-hub`.
- Compacte balk onderaan (zoals de oude Context Hub) en statusbalk: story, branch, PR met stemmen, pipeline, open threads, meldingen (`aihub watch events`) en Fabric (runs en fouten van de feature-workspace). Details achter een klik.
- Acties gaan naar je chat met de agent `aihub` geselecteerd en het juiste slash command ingevuld (Copilot Chat of opencode); lezen gebeurt direct.
- Reviewthreads in de editor: resolve, won't fix, reactivate, reply en "Fix in chat".
- Branch-menu (reset naar branch/commit, merge-conflictcheck, clean up unrelated, squash, switch) en Worktree Sets in de Explorer (maken, openen, repos toevoegen, sync, push, PR's via chat, gemergde opruimen, repogroepen).
- Learn: persoonlijke Learn-view met lessen en concepten, lespagina met Mermaid-diagrammen (vóór/na, architectuur, flow, lineage), rondleiding in de editor, quiz, "I know this", en "Play story / Open in iDiagram" als iDiagram is ingesteld.
- Chat-acties in de oude menu's (DevOps, Pull request, Pipeline, Project wiki, Robot tests, Source Control, Timeline, editor).

## Context
De oude 2.x-extensie draaide een eigen Java-core; 3.0.0 bevat geen logica meer: alles komt uit `aihub <cmd> --json`. Snel en licht: verversen bij focus, branchwissel of interval (standaard 60 s), niets op de achtergrond zonder focus, niets bij het opstarten.

## Compatibiliteit
VS Code 1.95+. Vereist aihub CLI 1.0.4 of nieuwer (`npm i -g @ferronhooi/aihub`); stemmen en events hebben de 1.0.3-lijn nodig. Optionele agents via `aihub skills install`. Oude 2.x-resten: `aihub legacy remove`.

## Validatie
Unit-tests (typecheck + vitest) groen; live in een geïsoleerd VS Code-profiel tegen de synthetische ferron-test-wereld: balk met echte stemmen en echte Fabric-data, klik → chat met agent aihub, opencode-route, alle branch- en worktree-set-acties met git als tweede bron, reviewthreads resolve/reactivate/won't fix/reply met az als tweede bron, Learn-pagina, rondleiding, quiz en iDiagram Play story. Zie docs/live-verification.md. Niet live: een echte Copilot Chat-agentrun (geen Copilot-credits).

## Installatie
`Install-Extensions` (extensions-repo) of `code --install-extension ai-context-hub-3.0.0.vsix` (controleer de sha256-asset). Niet op de Marketplace.
