# AI Context Hub 3.10.0 (VS Code)

## Wat is nieuw
- Geen wijziging in de extensie zelf. Deze versie hoort bij aihub 1.11.0: code-richtlijnen (`aihub guidelines`, de skill `code-guidelines`), de PR-titel uit team.yaml (de preview van Team Settings toont die), en skills en prompts die klaar zijn voor collega's zonder extensie.

## Context
Uitgebracht samen met aihub 1.11.0, zodat de versies bij elkaar horen.

## Snelheid
Niets veranderd: geen timer, geen watcher, niets in rust.

## Compatibiliteit
- Vraagt aihub 1.10.0 of nieuwer voor de knoppen; 1.11.0 voor de richtlijnen en de titel uit team.yaml.
- Werkt met PyCharm Git 0.31.x en 0.32.0.

## Validatie
- `npm run typecheck` en `npm run test:unit` op de releasebron; de telling staat in de release-PR.
- Geen nieuwe live-check: de extensiecode is gelijk aan 3.9.0.

## Known issues
- Geen nieuwe.

## Installatie
`install\Install.cmd` keuze [1] installeert aihub en de extensie, of installeer de vsix uit deze release. Herstart daarna VS Code helemaal.
