# aihub 1.8.1

The pipeline repair workflow selects a representative check, verifies the intended run context and follows an explicit monitoring request to completion. PR creation and updates connect each change to an expected result and observed evidence. Existing review criteria, team headings and links guide subsequent updates.

Pipeline reruns now preserve YAML template parameters and pin the queued revision. Existing runs with different parameters are excluded from reuse. Recording a run preserves manually authored review tables.

The bundled English and Dutch PR templates support optional user actions, rollout and open questions. Existing team templates keep their current behavior. To opt in, place `<!-- aihub:optional -->` on its own line in the section body. Section edits prefer exact heading matches. Oversized description updates report the excess before sending the request.

Install the CLI package and run `aihub skills install` to update installed skills. Teams maintaining their own PR template can adopt the bundled sections individually.
