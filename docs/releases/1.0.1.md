# aihub 1.0.1

## Wat is nieuw
- `aihub pr create` vult een lege sectie Wijzigingen/Changes zelf met de commits (onderwerp + sha) en de omvang van de diff, en een lege sectie Tests eerlijk met "Nog niet uitgevoerd." (of "Not run yet." bij een Engels team). Tekst van de agent wordt nooit overschreven.
- Elke skill werkt op zichzelf: geen verwijzingen meer naar `_shared`, zodat `npx skills add MyDataIntelligence/aihub -g` dezelfde skills geeft als `aihub skills install` (slash commands en de opencode-permission komen alleen uit `aihub skills install`).

## Context
Gevonden bij de schone-installatiecheck van 1.0.0 (docs/live-verification.md, "Clean install 1.0.0"): een /pr in opencode liet Changes en Tests leeg, en drie skills linkten naar `_shared`, dat de npx-route niet meeneemt.

## Compatibiliteit
Geen brekende wijzigingen ten opzichte van 1.0.0. Node >= 18.

## Validatie
- vitest 424 groen, skill-lint groen (CI weigert nu links naar mappen met een underscore en controleert naam/description van elke skill).
- Nieuwe tests: Changes/Tests-vulling, ook end-to-end `--dry-run` voor een Nederlands en een Engels team.

## Installatie
`npm i -g @ferronhooi/aihub@latest && aihub skills install`, of `aihub update`.
