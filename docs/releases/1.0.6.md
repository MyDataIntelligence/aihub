# aihub 1.0.6

## Wat is nieuw
- `/leer` slaat ook een les op bij een vraag zonder PR ("hoe werkt dit team"): de skill schrijft en bewaart de uitleg, en `learn validate`/`learn save` crashen niet meer op feiten van `learn repo` of `learn onboarding` (die geen `files` hebben).
- `aihub learn change --branch` vergelijkt met het echte doel: eerst de doelbranch van de actieve PR, dan `defaultTarget` uit team.yaml, pas daarna de standaardbranch.
- `aihub learn item` op een pipeline-yaml toont template-jobs en -steps als `template <pad>` in plaats van leeg.
- Docs: `tellAColleague` is een lijst van minstens 2 zinnen (gelijk aan de validator).

## Context
Gevonden bij de laatste live bewijzen van 1.0.5/3.0.0 op echte synthetische data.

## Compatibiliteit
Geen brekende wijzigingen. Extensie 3.0.0 blijft geldig.

## Validatie
vitest en skill-lint groen in CI; live: alle learn-commando's op een kloon van test-project met git als tweede bron (docs/live-verification.md, "Final proofs").

## Installatie
`aihub update`, of `npm i -g @ferronhooi/aihub@latest && aihub skills install`, of `Install-Extensions`.
