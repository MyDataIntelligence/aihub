# aihub 1.0.8

## Wat is nieuw
- **Meerdere repositories op dezelfde branch tegelijk openen.** `aihub worktree open --group <naam> --branch <branch>` (of `--repos a,b,c`) geeft elke repository de branch (bestaat hij lokaal of op origin: gebruiken; anders aanmaken vanaf `--from` of het `defaultTarget` van die repository in team.yaml, lokaal, niet gepusht), maakt per repository een worktree (de gewone checkout blijft ongemoeid; `--mode switch` schakelt de checkouts om en slaat een repository met niet-gecommitte wijzigingen over, de rest gaat door) en opent een VS Code-venster met alle mappen in een `.code-workspace` (`--window this` hergebruikt het venster). Resultaat: een compacte tabel per repository, of `--json`.
- `aihub worktree groups list|save <naam> --repos a,b|remove <naam>`: groepen staan in de eigen gebruikersconfig (`~/.config/aihub/groups.json`), nooit in een werkrepository; team.yaml-regels met `repositories[].groups: [naam]` tellen ook mee. `aihub worktree branches --group <naam>` toont waar een branch bestaat (bijvoorbeeld 2 van 3). `aihub worktree remove --branch <b>` ruimt zo'n set op (de branch blijft).
- **Rustige achtergrond op Windows.** Elk kindproces (git, az, node, de PowerShell van de toast, `aihub open`) start via een wrapper met `windowsHide: true`; de toast en het logon-item draaien PowerShell verborgen en niet-interactief achter `conhost --headless`; de `aihub://`-handler heeft geen console. Er verschijnt geen venster en niets pakt de focus meer tijdens het volgen van een pipeline.
- **Minder meldingen.** Per poll-ronde maximaal een toast ("aihub · 3 nieuwe dingen: !42 2 comments · review gevraagd op !51") met Open en "Stil 1 uur", nooit meer dan een per 2 minuten. `aihub watch config --notify all|needed|off` (standaard `needed`: vermeldingen, gevraagde reviews, antwoorden op mijn comments, mijn rode builds; gewone nieuwe comments staan alleen in `aihub watch events`) en `aihub watch quiet --for 1h | --until 18:00 | --off`.
- De VS Code-extensie krijgt hiervoor in een eigen release een ingang (chip "Repos op branch openen"); dit pakket bevat alleen de CLI.

## Context
De gebruiker wil zijn repositories op C: in een keer op dezelfde branch openen en de worktree-keuze zichtbaarder hebben, en zag het terminalvenster naar voren springen en te veel meldingen langskomen bij `aihub`/npm.

## Compatibiliteit
Geen brekende wijzigingen. `watch --mine --notify` toont nu standaard alleen wat een reactie van de gebruiker nodig heeft (voorheen elk event); `aihub watch config --notify all` herstelt het oude gedrag. Een bestaande aihub://-registratie wordt bij de eerstvolgende `watch --notify` opnieuw geschreven (met `conhost --headless`).
