# aihub 1.0.5

## Wat is nieuw
- Learn 2.0 compleet: `aihub learn diagram` (architectuur, lineage, repo, flow; Mermaid alleen uit feiten), `learn flow|glossary|week|onboarding|item`, iDiagram-push met "Play story" (eenvoudige import en rijke boards via `/boards/build`), je niveau (`aihub learn level set junior|medior|senior`) en een optioneel lesaanbod na een PR (`aihub learn after-pr on`). Alles blijft persoonlijk in ~/.config/aihub/learn.
- De Fix-knop in een melding start nu een nieuwe opencode-sessie in de repo met agent `aihub` en `/fix <run-url>` (hervatte eerst de sessie van een ander project; live gevonden).
- `aihub pipeline approvals approve|reject` weigert ACC en PRD nu ook als Azure DevOps geen environment noemt: de environment komt uit de pipeline-YAML van de run; lukt dat niet, dan weigert het commando (alleen `--allow-env <stage>` op uitdrukkelijk verzoek).
- Pipelines live bewezen, met fixes: artifacts downloaden van de artifacts-host, de environment van een approval via de timeline, en approvers die alleen een id hebben.
- De VS Code-extensie AI Context Hub 3.0.0 komt tegelijk uit (GitHub-release `vscode-v3.0.0`, zie vscode/docs/releases/3.0.0.md).

## Context
Laatste release van de eindlijst: Learn 2.0 is volledig terug (visueel uitleggen voorop) en de laatste live gevonden fouten zijn opgelost.

## Compatibiliteit
Geen brekende wijzigingen. Node >= 18.17. iDiagram is optioneel; zonder iDiagram werkt Learn volledig met Mermaid.

## Validatie
vitest en skill-lint groen in CI; live in ferron-test en een geïsoleerd VS Code-profiel: learn diagram en iDiagram (boards aangemaakt, Play story geklikt), quiz/concepten/"I know this" geklikt, afterPr bij een echte `pr create`, de Fix-knop echt geklikt (opencode opent met /fix), approvals ACC-weigering en pipelines met een synthetische pipeline en environment. Zie docs/live-verification.md.

## Installatie
`aihub update`, of `npm i -g @ferronhooi/aihub@latest && aihub skills install`, of `Install-Extensions`.
