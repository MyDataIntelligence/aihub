# aihub 1.0.2

## Wat is nieuw
- Slash command `/story-run <story id of link>` (opencode, Codex-prompt en Copilot-prompt): start de skill `story-run`, die een story zonder vragen tot een groene PR brengt. Komt uit `aihub skills install` (de npx-route geeft de skills, geen slash commands).
- `aihub test changed [--base <branch>] [--run]`: de tests die bij de gewijzigde bestanden horen (team.yaml `tests.command` en `tests.map`, anders heuristieken voor Python en JS/TS); met `--run` draait alleen die selectie. De skills implement, story-run en pipeline-fix zeggen: nooit de hele suite lokaal, de pipeline doet dat.
- `aihub commit` meldt vóór het commit welke git hooks van de repository draaien ("git hooks running: pre-commit, ...") en na afloop hoe lang ze duurden (ook bij `--push` voor pre-push). `--no-verify` slaat de hooks over en mag alleen als de gebruiker daar zelf om vraagt (staat zo in de skill); de hooks van de repository worden niet aangepast.

## Context
De skill bestond al; alleen de slash command ontbrak. Uit een echte werkdag in opencode: de agent draaide de volledige testsuite (2163 tests) zelf en `aihub commit --push` duurde minuten omdat de hooks de suite nog eens draaiden.

## Compatibiliteit
Geen brekende wijzigingen. Node >= 18.

## Validatie
vitest en skill-lint groen (de lint controleert dat de commandobestanden gelijk zijn aan de skill).

## Installatie
`npm i -g @ferronhooi/aihub@latest && aihub skills install`, of `aihub update`.
