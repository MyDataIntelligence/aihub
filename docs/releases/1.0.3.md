# aihub 1.0.3

## Wat is nieuw
- Optionele agents voor opencode en GitHub Copilot: `aihub` (primair, werkt via de skills) en `aihub-runner` (subagent voor lange klussen: story-run, pipeline-fix, pr-watch, review-process; rapporteert in maximaal 5 regels). Ze komen mee met `aihub skills install`; `--no-agents` slaat ze over, `aihub skills uninstall` haalt ze weg, `aihub skills update` ververst ze waar ze staan, `--into-repo` schrijft `.opencode/agents/` en `.github/agents/`.
- `aihub doctor` toont per client een regel `agents:<client>` (optioneel als ze ontbreken, een fix als de kopie ouder is dan de CLI).
- `--client copilot` is een alias van `--client github-copilot`.
- `npm run lint:skills` controleert ook de agentbestanden: geldige front matter, maximaal 25 regels body, dezelfde body voor beide clients, geen absolute paden of echte namen, alleen bestaande skills.

## Context
De skills doen het werk, maar de standaardagent van een client weet niet dat hij ze moet gebruiken en vraagt vaak om dingen die een skill of `team.yaml` al beantwoordt. Wie dat wil kiest nu bewust de agent `aihub`; de standaardagent blijft ongemoeid. De agent herhaalt geen skilltekst: de skills blijven de bron van waarheid.

## Compatibiliteit
Geen brekende wijzigingen. Node >= 18. De agents zijn optioneel. Een bestand dat je zelf bewerkte, of een bestand met dezelfde naam dat aihub niet schreef, wordt nooit overschreven (zelfde regel als bij skills). opencode: de bestanden komen in `agents/` met het `permissions`-formaat van opencode 2; in opencode 1 worden de rechten genegeerd en vraagt opencode zelf om toestemming. Voor VS Code kan een agentbestand geen terminalgoedkeuring geven: dat is de VS Code-instelling `chat.tools.terminal.autoApprove` (voorstel in `docs/agents.md`). Claude Code en Codex krijgen nog geen agent (Codex kent TOML-agentbestanden; dat is nog niet geverifieerd).

## Validatie
vitest (agent-installatie in nepthuismappen, nooit de echte; lint-tests) en skill-lint groen. Niet gedaan: de agents zijn nog niet live gekozen in opencode, VS Code of de Copilot CLI.

## Installatie
`npm i -g @ferronhooi/aihub@latest && aihub skills install`, of `aihub update`. Kiezen: zie `docs/agents.md`.
